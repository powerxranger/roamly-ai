1
Sequential vs Parallel Flow
Currently executes sequentially: Flight → Hotel → Weather → Itinerary → Final. Because Flight, Hotel, and Weather only depend on the initial destination/query, they can be parallelized in LangGraph using fan-out edges to slash request latency by up to 60%.
2
Dual MCP Server Typology
Roamly separates MCPs by runtime type: Local stdio for subprocesses (AviationStack via uvx with mcp<2 pin and local FastMCP weather_server.py) vs Remote HTTP (Tavily search via streamable_http). Isolated loading prevents cascade failure.
3
Fail-Soft Redis Caching
Redis is treated as a pure optimization layer. If Redis drops connection, calls automatically fall through to live APIs. Key hashes use deterministic SHA256 fingerprints, and TTLs range from 7 days for airport data down to 10 minutes for live weather.
4
Multi-Turn Postgres State
State snapshots are serialized per thread_id using langgraph-checkpoint-postgres. This allows full conversation continuity, debugging state replay, and session recovery across browser restarts without bloating memory.
